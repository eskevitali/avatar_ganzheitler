# Профиль user-mask

Единственный поставляемый пакет — `assets/user-mask/`. Манифест `profile.json` указывает на `user-mask-b358fbc4aeb1.glb`; GLB содержит текстуру и буферы. Контрольная сумма записана в `revision.json`. Для передачи доступен `releases/user-mask-2026-10-24-empty-mouth.zip`.

```bash
node scripts/install-profile.mjs assets/user-mask
```

Установщик проверяет манифест, GLB, именованные узлы и morph targets, затем атомарно создаёт `public/profiles/user-mask/`. Повторная установка в существующую папку отклоняется. `public/profiles/` не отслеживается Git. Каталог перечисляет установленные пакеты; встроенной учебной куклы нет. Локальный preview устанавливает актуальный пакет автоматически, если он отсутствует.

Формат манифеста v1 описан валидатором `public/profiles.mjs`: обязательны formatVersion, id, name, model, body. Модель — имя GLB без пути; body — F/M. Настройки губ и внешности дополняются значениями по умолчанию. Контракт rig/morph проверяет `profile-store.mjs`. В пакете нет исполняемых скриптов.

Мимика: neutral/happy/sad/angry/fear. Движения головы и глаз регулируются независимо от 0 до 300%, эмоции — от 0 до 200%. Настройки сохраняются отдельно для каждого профиля; голос ElevenLabs остаётся общей серверной настройкой. Фон имеет собственное хранилище.

Старые пакеты оставлены локально вне отслеживания; для чистой установки достаточно текущего пакета. Исходник и лицензии: [USER_MASK_CHECKPOINT.md](USER_MASK_CHECKPOINT.md).
