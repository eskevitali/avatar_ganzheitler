# Avatar

Текст озвучивается через ElevenLabs; объёмная маска движется, моргает и артикулирует речь. В текущем дереве Git поставляется один принятый профиль: **user-mask**, модель `user-mask-b358fbc4aeb1.glb`, с прозрачным пустым проёмом рта.

## Локальный запуск

Нужен Node.js 22. Настройки ElevenLabs задаются переменными окружения (см. `.env.example`); секреты храните вне Git.

```bash
node --env-file=.local-preview/elevenlabs.env scripts/local-preview.mjs
```

Preview устанавливает текущий профиль при первом запуске, создаёт локальные пароль и секрет сессии в игнорируемой `.local-preview/` и слушает порт 3100. Существующие настройки сохраняются. Обычный сервер запускается `node server.mjs` после установки профиля и задания переменных окружения. Dockerfile устанавливает этот же профиль при сборке; публикация не выполняется автоматически.
